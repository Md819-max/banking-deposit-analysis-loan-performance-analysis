# banking-deposit-analysis-loan-performance-analysis
Data analytics project analyzing deposits and loan performance using Python, SQL, and Power BI.
🏦 Banking Deposit & Loan Analysis

This project focuses on analyzing banking deposit and loan datasets to uncover key financial insights, identify customer trends, and evaluate loan risk and repayment patterns.
The analysis combines Python (pandas, matplotlib), SQL, and Power BI for visualization and business reporting.

Key Objectives

Analyze deposit growth trends and customer saving patterns

Evaluate loan approval rates, defaults, and repayment performance

Apply regression and correlation analysis for risk assessment

Build interactive dashboards for data-driven decision-making

Tools & Technologies

Python (pandas, numpy, scikit-learn)

SQL

Power BI

Excel

Key Insights

Deposits showed a steady increase in high-value customers across savings accounts.

Loan defaults were higher in mid-income segments with longer tenure periods.

Time-series models helped forecast loan repayment probabilities.
